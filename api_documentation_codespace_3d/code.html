POST

/v1/assets/upload

Beta

Uploads a new 3D asset or texture map to the active project workspace.

data_object Request Body

Field Type Description
file REQ binary The GLTF, GLB, or image file to upload. Max size 50MB.
project_id string (uuid) Target project UUID. Defaults to currently active project if omitted.
optimize boolean If true, automatically runs Draco compression on geometry. Default: false.

Example Request

curl -X POST \
  https://api.codespace3d.com/v1/assets/upload \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Content-Type: multipart/form-data' \
  -F 'file=@/path/to/model.glb' \
  -F 'optimize=true'

Responses

{
  "status": "success",
  "data": {
    "asset_id": "as_9x8f7d6e5",
    "url": "https://cdn.cs3d.com/as_9x8f7d6e5.glb",
    "size_bytes": 2450981,
    "optimized": true,
    "created_at": "2024-03-15T10:23:41Z"
  }
}
